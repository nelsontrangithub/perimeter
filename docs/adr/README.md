# Architecture Decision Records

One file per decision, numbered in the order they were made. Each states the context, the
decision, its consequences, and what would make us reverse it. A superseded ADR is marked
superseded at the top and left in place; history is not rewritten.

| [003](003-ports-and-adapters-stdlib-core.md) | Ports and adapters with a stdlib-only core | Accepted |
